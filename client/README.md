# Клиент Collab App

Клиент — одностраничное React-приложение, через которое пользователь работает
с аккаунтом, проектами, участниками и совместными вкладками.

## Технологии

- React 18 и React Router;
- Vite;
- Axios;
- Tiptap для текстового редактора;
- Excalidraw для доски;
- Yjs и Hocuspocus Provider для realtime-синхронизации;
- SCSS и CSS Modules.

## Структура

Код организован по слоям:

```text
src/
├── app/       # запуск приложения, провайдеры, маршруты и глобальные стили
├── pages/     # страницы и загрузка данных страницы
├── widgets/   # крупные блоки: Header, ProjectGrid, TabGrid
├── features/  # формы, настройки, участники и редакторы
├── entities/  # UI доменных сущностей
└── shared/    # API-клиент, realtime, ссылки и UI-примитивы
```

Верхние слои могут использовать нижние. Общие модули из `shared` не должны
зависеть от страниц или конкретных пользовательских сценариев.

## Маршруты

Публичные:

- `/` — стартовая страница;
- `/login` — вход;
- `/register` — регистрация.

Защищенные:

- `/projects` — список доступных проектов;
- `/projects/:projectId` — вкладки, участники и настройки проекта;
- `/projects/:projectId/tabs/:tabId` — редактор вкладки;
- `/settings` — настройки аккаунта.

## Авторизация и HTTP

Все запросы выполняются через `src/shared/api/axios.js`.

Access token хранится в `localStorage` и автоматически добавляется в
`Authorization: Bearer ...`. При истечении access token Axios пытается получить
новый токен через `/api/auth/refresh`. Refresh token передается браузером в
`httpOnly` cookie.

Компоненты могут скрывать недоступные действия по роли пользователя, но
сервер остается единственным источником решения о доступе.

## Совместные редакторы

`EditorRenderer` выбирает редактор по типу вкладки:

- `text` открывает Tiptap;
- `board` открывает Excalidraw.

Оба редактора подключаются к Hocuspocus по значению
`tab.ydoc_document_name`. Токен пользователя передается при WebSocket-
аутентификации.

Для `viewer` редакторы работают в режиме только для чтения. При изменении
realtime-кода важно:

- не записывать данные до первоначальной синхронизации;
- очищать observers, события provider и таймеры;
- не менять имена структур Yjs без миграции;
- проверять одновременную работу минимум в двух браузерных сессиях.

## Переменные окружения

```dotenv
VITE_BACKEND_URL=http://localhost:5000
VITE_WS_URL=ws://localhost:1234/api/collab
```

## Команды

```bash
npm ci
npm run dev
npm run lint
npm run build
npm run preview
```

`npm run dev` запускает Vite на `0.0.0.0`. Production-сборка создается в
`client/dist`.

## Добавление функциональности

- API-вызовы следует выполнять существующим Axios-клиентом.
- Бизнес-логику не нужно переносить в `shared/ui`.
- Новый тип вкладки требует изменений не только в клиенте, но и в серверном
  валидаторе, сервисе и схеме БД.
- Пользовательские строки желательно писать на языке окружающего интерфейса.
